# Dead Code Cleanup Design

## Intent

현재 실행 경로에서 사용하지 않는 코드와 주석 처리된 옛 구현을 제거해 코드를 읽기 쉽게 만든다.

## Goals

- 실행 진입점에서 도달하지 않는 모듈을 제거한다.
- ESLint가 확인한 미사용 import, 변수, 상태를 제거한다.
- 주석 처리된 옛 코드와 코드 내용을 반복하는 주석을 제거한다.
- 현재 동작과 사용자가 수정 중인 코드는 보존한다.

## Non-goals

- React Hook 의존성 경고를 고치지 않는다.
- 장면 전환, 카메라, 오디오의 동작을 바꾸지 않는다.
- 미참조 에셋과 npm 의존성은 이번 정리에서 제거하지 않는다.

## Approach

정적 import 그래프와 ESLint 결과를 근거로 확실한 항목만 단계적으로 제거한다. 각 단계 뒤에 ESLint를 다시 실행하고, 마지막에 테스트와 프로덕션 빌드를 시도한다. Git 기록으로 복구할 수 있으므로 주석 처리된 옛 코드는 보존하지 않는다.

## Constraints

- 현재 작업 트리의 사용자 변경을 덮어쓰지 않는다.
- 설명의 이유를 담은 주석은 남긴다.
- 불확실한 코드, Hook 의존성, 에셋은 건드리지 않는다.
