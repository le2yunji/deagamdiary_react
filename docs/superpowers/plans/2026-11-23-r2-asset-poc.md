# Cloudflare R2 Asset PoC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Gamza_cycle.glb` 한 개를 R2에서 브라우저로 안전하게 로드해 전체 에셋 이전 가능성을 검증한다.

**Architecture:** R2에는 기존 `assets/...` 키 구조를 유지한다. React는 `REACT_APP_ASSET_BASE_URL`을 URL 헬퍼로 결합하며, 값이 없으면 기존 Vercel 상대 경로를 그대로 사용한다.

**Tech Stack:** React 18, Create React App 5, React Three Fiber, Cloudflare R2 Standard, Jest

**Spec:** `docs/superpowers/specs/2026-11-23-r2-asset-poc-design.md`

## Global Constraints

- PoC 대상은 `public/assets/models/Gamza_cycle.glb` 한 개다.
- R2 객체 키는 `assets/models/Gamza_cycle.glb`다.
- 비밀키와 API 토큰은 코드, 환경 파일, Git에 저장하지 않는다.
- CORS는 localhost와 Vercel 운영 origin의 `GET`, `HEAD`만 허용한다.
- 환경변수가 없으면 기존 `/assets/...` 경로로 되돌아가야 한다.
- `r2.dev`는 PoC용 임시 주소이며 운영 전에는 `assets.<domain>` 형태의 커스텀 도메인으로 교체한다.
- 사용자 작업 중인 파일의 다른 변경은 커밋에 포함하지 않는다.

## Review Focus

- base URL 끝의 `/` 유무와 asset path 앞의 `/` 유무가 중복 슬래시를 만들지 않아야 한다.
- 환경변수가 없을 때 기존 상대 URL이 보존되어야 한다.
- GLB 응답의 `Content-Type`이 `model/gltf-binary`여야 한다.
- 허용하지 않은 origin에 쓰기 권한이 생기지 않아야 한다.
- preload와 실제 `useGLTF` 호출이 같은 URL을 사용해야 한다.
